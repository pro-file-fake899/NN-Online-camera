# NN Online Camera — APK Build Guide (Created by Nabhnish Kumar)

## Option 1: Bina PC ke (Mobile se GitHub par Free APK Banayein)
1. GitHub par ek naya repository banayein (e.g. `nn-online-camera`).
2. Is ZIP ke saare files ko us repo mein upload/push karein.
3. Repo ke **Actions** tab mein jayein -> **Build NN Online Camera APK** -> **Run workflow** click karein.
4. 2 minute mein **NN-Online-Camera-APK** (`app-debug.apk`) download karne ke liye ready mil jayega!

## Option 2: Android Studio (PC par)
1. Is folder ko Android Studio mein Open karein.
2. Gradle sync complete hone dein (`google-services.json` aur logo pehle se added hain).
3. Top menu mein **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** click karein.
4. APK file `app/build/outputs/apk/debug/app-debug.apk` par ban jayegi.
